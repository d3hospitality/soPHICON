# soPHICON ER-G2

G2 smart glasses philosophy app — explore philosopher quotes, sprites, and wisdom through the Even Realities G2 AR interface.

## Claude Skills

| Skill | What it does here |
|---|---|
| **g2-app-scaffold** | Scaffolds new G2-optimized views and routes for the glasses UI |
| **d3-brand-system** | Applies D3 Hospitality brand colors, fonts, and visual identity |
| **quote-pipeline** | Processes philosopher quotes from spreadsheets into app-ready JSON |
| **sprite-pipeline** | Generates and manages philosopher sprite assets |
| **g2-container-layout** | Layouts content within G2 glasses display constraints |
| **vercel-api-proxy** | Sets up Vercel serverless proxy endpoints for external APIs |
| **dev-log-writer** | Generates structured dev log entries for session work |
| **claudemd-generator** | Creates and updates CLAUDE.md project context files |
| **command-launcher** | Builds .command launcher scripts for common workflows |

## Quick Start

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build

# Deploy to Vercel
vercel --prod
```
