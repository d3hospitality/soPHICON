## 2. Folders / files to strip before zipping

| What | Why | Action |
|------|-----|--------|

| `dist/` | Build artifact, reproducible via `npm run build` | delete before zip |
| `.vercel/` (both at repo root and `sophicon-api/.vercel/`) | Contains your Vercel `projectId` + `orgId` — not secrets but personally identifying | delete before zip |

| `.DS_Store` (any) | Mac Finder metadata | delete (or ensure gitignored) |

## 3. Content-vs-app boundary

Four pieces are **content, not app**. Reviewers should understand these won't apply to their use case — mentioned in README but worth repeating:

- `src/constants.ts` — 2,801 philosophical quotes, auto-generated from an authoring JSON (not in repo)
- `public/personas.json` — persona sheets with tone/voice/principles for the 17 philosophers
- `public/sprites/` — 391 pixel-art PNGs, generated by a separate sprite pipeline (not in repo)
- `sophicon-api/` — Vercel serverless functions; useful as a template but the keys + deployment are mine

5. **Friction points** — `NOTES-FOR-EVEN-REALITIES.md` ranks the 15 things that cost me the most time, with suggested fixes. Most useful doc in the drop.
