These are the SDK surfaces exercised by src/Main.ts and src/events.ts. Anything not listed here is unused by soPHICON.

used in: src/Main.ts

Push: connect / disconnect / battery. Drives the green/red dot + "— battery 83%" log lines.
used in: src/Main.ts

Glasses UI — containers

bridge.createStartUpPageContainer(cfg) → 0|1|2|3
One-shot. Must be called exactly once at boot. Max 4 containers, exactly one has isEventCapture:1. Coord origin is top-left, X right, Y down.
used in: src/Main.ts → buildHomePage()
bridge.rebuildPageContainer(cfg) → boolean
Every screen after the first uses this — home, philosopher select, mindstate, quote view, speak flow.
used in: src/events.ts (all navigation)
bridge.updateImageRawData({ containerID, containerName, imageData })
Pushes the grayscale PNG bytes for an image container. Must be serialized — no concurrent pushes. soPHICON queues awaits.
used in: src/image-utils.ts → pushImg()
bridge.textContainerUpgrade({ containerID, content, contentOffset, contentLength })
Swap text in a text container without a full rebuild. Not currently used — soPHICON rebuilds the page on each quote; could speed up auto-rotate.
potential optimization for quote rotation
bridge.shutDownPageContainer(exitMode?)
0 exits immediately, 1 shows the foreground interaction layer. Not currently wired — no explicit exit path.
unused

Events & audio

bridge.onEvenHubEvent(cb) → unsubscribe
Fires for listEvent (scroll / click on the ring), sysEvent (single / double click), and audioEvent (PCM stream).
used in: src/events.ts → handleEvent()
bridge.audioControl(isOpen)
Opens / closes the mic. PCM arrives as event.audioEvent.audioPcm Uint8Array: 16 kHz, 16-bit LE, 40 bytes per 10 ms frame.
used in: src/speak.ts → startRecording / stopRecordingAndSend

Sprite pipeline — how pixel-art philosophers hit the glass

23 emotions × 17 philosophers = 391 sprites. Every sprite goes through a custom grayscale PNG encoder before the SDK will accept it — the glasses' framebuffer can't render arbitrary PNG formats.

1
Source PNGs public/sprites/<phil_id>/<phil_id>-<emotion>.png
e.g. socrates/socrates-conviction.png. Emotions used: neutral · contemplation · conviction · wonder · serenity · defiance · sorrow · urgency · joy · compassion · awe · acceptance · authority · devotion · doubt · grief · honor · liberation · peace · rage · resolve · teaching · transcendence.
folder
↓
2
Fetch + canvas fit fetchAsGrayscalePng() in src/image-utils.ts
Scales into target box with letterbox, fills bg black, reads pixels, then grayscale: g = 0.299·R + 0.587·G + 0.114·B.
edit
↓
3
Encode encodeGrayscalePng() in src/pngEncoder.ts
Custom encoder: 8-bit grayscale, no filter, uncompressed DEFLATE blocks, Adler32 + CRC32 checksums. ~120 lines, no deps. The G2 firmware expects this exact shape.
edit
↓
4
Push pushSpriteSingle / pushSpritesSplit
Split: 200×200 sprite → two 200×100 halves for the big portrait (containers 3 top + 11/12 bottom). Single: 100×100 for the speak conversation face.
same file
↓
5
On glass bridge.updateImageRawData({ containerID, imageData })
Bytes become an ImageContainerProperty. Rule: never concurrent — always await the previous push. Memory on-glass is tight.
runtime

To add or swap sprites

# 1. Drop PNGs into public/sprites/<phil_id>/<phil_id>-<emotion>.png
#    — any source size works; encoder downscales to target (100x100 or 200x200)
#    — prefer simple, high-contrast pixel art (grayscale collapse is lossy)
# 2. If the emotion is new, add it to:
#    src/speak.ts → emotionToSprite() valid[] array
#    sophicon-api/api/speak.js system prompt emotion list
# 3. Wire a quote to it by setting the `sprite` field in the source JSON,
#    then regenerate constants.ts (see Quote pipeline above).

API keys & the Speak pipeline

The SDK does not store keys. All keys live server-side on Vercel as env vars — they must never enter the web bundle.

POST https://sophicon-api.vercel.app/api/speak
Calls GPT-4o with the persona + history. Reads process.env.OPENAI_API_KEY. System prompt builds from public/personas.json. Returns { text, emotion } (emotion parsed from [EMOTION:tag] line).
file: sophicon-api/api/speak.js
POST https://sophicon-api.vercel.app/api/transcribe
Takes base64 PCM from the glasses mic, wraps it in a WAV header (16 kHz, 16-bit, mono), forwards to gpt-4o-transcribe. Optional language (ISO 639-1).
file: sophicon-api/api/transcribe.js · uncommitted diff: language param added

Rotating / adding keys

# On Vercel (sophicon-api project):
vercel env add OPENAI_API_KEY production
vercel --prod                  # redeploy so the function picks it up

# Do NOT put the key in .env bundled with the Vite app — everything in src/ ships to the client.
