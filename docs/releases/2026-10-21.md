## Security and cost controls

No schema or RLS changes. Existing owner-only device_sync rows store goal, path_move and habit entities. Planner resolves authenticated owner and stored goal before model spend. It validates 1–3 actions and a total within the user's 5–120 minute budget, caches by goal revision/day and permits six new plans per account per UTC day. Suggestions require an explicit Keep action.

Conversation/transcription/TTS throttles are 6 requests/minute for anonymous visitors and 10/minute for signed-in users; Sage and free accounts use the same pace. Existing shared anonymous service budgets remain 300/day for speak and transcribe. There is no paid daily conversation allowance. TTS now uses the working Supabase KV adapter and no separate legacy daily cap. Optional Sage and concept commissions keep existing pricing/fulfillment.
