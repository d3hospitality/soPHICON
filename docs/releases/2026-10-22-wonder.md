# enkiRIDION 1.17.0 — A moment of wonder

Fourteen curated daily invitations connect an existing-library quote with an original question and a short experiment. Browse from Wonder on the glasses home menu, My day, or the companion Today card. Connect an active goal to use its goal-oriented experiment. Nothing is saved until Keep this step. Kept actions enter Make time/Q2 and support completion, priorities and habit conversion using the existing path and habit stores.

The website adds public `/wonder`, home/demo discovery and the same card in `/day`. Web saving needs a free account; unlinked Even users can keep locally. Shared local-calendar dates and day + moment identities avoid sequential duplicates; fresh sync/read checks preserve completed actions. Existing last-write-wins rules still govern simultaneous edits. Goal-less Wonder actions appear in My day without changing the filter for steps from inactive goals. `src/wonder.mjs` and web `lib/wonder.mjs` must remain byte-identical.

No new AI calls, database tables, permissions, paywalls or audio dependencies. Release source is the 1.16.1 styling worktree (`17260ed`) plus Wonder; unfinished quote-audio source on the main development branch is excluded.
